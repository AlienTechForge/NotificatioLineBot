### 本機環境注意（非專案問題）

開發機若裝有會 MITM TLS 的防毒（本機是 Avast，`SSLKEYLOGFILE=\\.\aswMonFltProxy\…`），Maven 會失敗於：

```
PKIX path building failed: unable to find valid certification path
```

curl 正常是因為它走 Windows 憑證庫，而 Java 用自己的 `cacerts`。解法是讓 JVM 改用 Windows 憑證庫：

```bash
MAVEN_OPTS="-Djavax.net.ssl.trustStoreType=WINDOWS-ROOT" mvn -f server/pom.xml verify
```

**不要**寫進 `.mvn/jvm.config` —— 那會讓 Linux 的 CI 掛掉。建議設成使用者層級的環境變數。
