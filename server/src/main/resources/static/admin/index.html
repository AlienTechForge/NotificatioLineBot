發送明細

新增監控

貼上匯入（cURL / fetch / 自訂 JSON）

要帶登入狀態請用 Chrome 的「Copy as cURL (bash)」——「Copy as fetch」不含 cookie。cookie 是瀏覽器自行附加的 forbidden header，不會出現在複製出來的字串裡；貼了「Copy as fetch」的內容會一直 401，不是設定壞了。 貼上的內容含 cookie 時會自動存進「登入狀態」頁，不會留在這個監控自己的 header 裡。

自訂 JSON 格式可以直接拿去餵給 AI，請它照這個 schema 產生一份可匯入的設定。

實際下限依伺服器設定（app.monitor.min-interval）而定，太低會在儲存時被拒絕。

只允許 https，且不可指向內網位址（伺服器端強制檢查）。

格式：扁平的字串對字串 JSON 物件。可用 {{computed.NAME}} 引用下面的計算欄位。留空 = 不變更既有 header。

密鑰（signing secret，例如 appsecret、device id）

計算欄位用 {{secret.NAME}} 引用。值加密儲存，後台只顯示名稱與「已設定」，絕不顯示值。

計算欄位（依序求值，可串接多段雜湊）

每個欄位的 steps 依序套用，前一段的輸出字串就是後一段的輸入——這是雙重雜湊 （例如 MD5(MD5(x).toUpperCase()).toUpperCase()）能表示的原因。輸入可用 {{secret.NAME}}、{{now.epochSeconds}}、{{uuid}}，以及 更早定義的 {{computed.NAME}}；模板（URL/header/body）用 {{computed.NAME}} 引用求出的值。

抽取欄位（JsonPointer，模板用 {{value.NAME}} 引用）

上面的抽取欄位在此模式下相對於每個項目解讀，模板用 {{item.NAME}} 引用。

可用 {{value.NAME}} {{old.NAME}} {{item.NAME}} {{monitor.name}} {{now}}。
